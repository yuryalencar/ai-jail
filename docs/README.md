# ai-jail docs

Supplementary documentation for ai-jail. The main [README](../README.md)
covers install + daily use; these files go deeper on specific topics.

- [installation.md](installation.md) — What `install.sh` changes on your
  host, what gets created on first use, and how to fully uninstall.
- [usage.md](usage.md) — Using one install across many projects,
  subcommands, and when the image/volumes actually get touched.
- [configuration.md](configuration.md) — Per-project `CLAUDE.md` vs.
  globally-shared skills, and how the volume layout enables both.
